# ByGigaBit — Платформа Paper Trading & Bybit V5

Повноцінна екосистема біржового термінала з реальною інтеграцією **Bybit Spot V5 API**, інтерактивними свічковими графіками **TradingView Lightweight Charts**, модулем безпеки **JWT & 2FA**, ролями доступу **RBAC (Trader/Admin)** та детальним **журналом аналітики**.

---

## Швидкий запуск

1. Запустіть сервер:
   - Двічі клікніть по **`start.bat`** (або виконайте в терміналі `python app.py`).
2. Відкрийте в браузері:
   - **http://localhost:8080**

---

## Реалізовані сторінки платформи

Усі сторінки мають роздільну чисту архітектуру (HTML + CSS + JS):

| URL | Сторінка | Опис та можливості |
| :--- | :--- | :--- |
| **`/`** | **Головна** | Промо-огляд, живі котирування Bybit Spot (BTC, ETH, SOL), навігація по модулях. |
| **`/chart`** | **Торговий термінал** | Живий графік TradingView (1m–1D), книга ордерів Bybit (Order Book), оформлення Market / Limit угод, кредитне плече $1\times$–$20\times$, розрахунок ціни ліквідації. Нижня панель: **Відкриті позиції**, **Лімітні заявки**, **Історія ордерів**, **Баланс**. |
| **`/auth`** | **Авторизація & 2FA** | Вхід / реєстрація, перевірка 6-значного коду підтвердження (2FA), швидкий вибір ролей Trader або Admin, формування сесії через JWT. |
| **`/analytics`** | **Аналітика & Журнал** | Розрахунок ключових біржових метрик: **Win Rate (%)**, **Profit Factor**, **Average R:R**, чистий PnL ($), SVG-графік зростання капіталу (**Equity Curve**), фільтри журналу угод. |
| **`/profile`** | **Профіль & Гаманець** | Стартовий депозит **$10,000 USDT**, кнопка миттєвого скидання балансу, перемикач Email 2FA, зміна пароля. |
| **`/admin`** | **Адмін-панель (RBAC)** | Системна статистика (кількість трейдерів, загальний об'єм угод, відкриті позиції), таблиця користувачів, пошук за email та кнопка **блокування / розблокування** акаунтів. |

## Реалізовані REST API ендпоінти
- `GET /api/klines?symbol=BTCUSDT&interval=15&limit=200` — свічкові дані Bybit V5.
- `GET /api/ticker?symbol=BTCUSDT` — ціна та 24h показники.
- `GET /api/orderbook?symbol=BTCUSDT` — стакан заявок (Bids / Asks).
- `GET /api/tickers` — зведені котирування популярних пар.
- `GET /api/wallet` & `POST /api/wallet/reset` — стан та скидання віртуального депозиту.
- `GET /api/terminal/state` — відкриті позиції, лімітні заявки та остання історія.
- `POST /api/terminal/order` — створення ринкових або лімітних угод з плечем до 20x.
- `POST /api/terminal/close-position` — закриття позиції та фіксація прибутку/збитку.
- `POST /api/terminal/cancel-order` — скасування відкладеної заявки.
- `GET /api/analytics/metrics` — розрахунок Win Rate, Profit Factor, кривої капіталу.
- `GET /api/admin/users` & `POST /api/admin/users/{id}/toggle-block` — керування доступом.
- `GET /api/admin/stats` — системна статистика платформи.
- `POST /api/auth/login` & `POST /api/auth/register` — авторизація та 2FA валідація.
